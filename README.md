# kpithesis — шаблон кваліфікаційної роботи КПІ

LaTeX-шаблон дипломної роботи/проєкту (бакалавр) та магістерської
дисертації для будь-якої кафедри КПІ ім. Ігоря Сікорського, що
відповідає **ДСТУ 3008:2015** (структура й оформлення тексту) та
**ДСТУ 8302:2015** (перелік посилань). Компілюється однаково на
Windows, Linux і в Overleaf; не залежить від сумнівних кириличних
шрифтів на кшталт PSCyr.

Якщо цікаво, чому шаблон побудований саме так — дивіться
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md). Цей файл — лише про
"як користуватись".

## Швидкий старт (Overleaf, без встановлення нічого)

1. Завантажте останній `.zip` шаблону зі
[сторінки Releases](https://github.com/xairaven/KPI-Thesis-Template/releases) 
цього репозиторію.
2. На [overleaf.com](https://www.overleaf.com) → "New Project" →
"Upload Project" → виберіть завантажений `.zip`.
3. Відкрийте `config.tex`, впишіть свої дані (див. розділ нижче).
4. Натисніть "Recompile".

Overleaf уже має все потрібне встановлено (XeLaTeX, biber, шрифти) —
додаткових кроків не потрібно.

## Локальна збірка (Windows / Linux)

Знадобиться дистрибутив TeX Live (Linux, зазвичай уже встановлений
або з пакетного менеджера дистрибутива) або MiKTeX (Windows,
[miktex.org](https://miktex.org)) — обидва містять XeLaTeX, `latexmk`
і `biber`. MiKTeX сам запропонує довстановити пакет, якщо чогось
бракує при першій збірці — погоджуйтесь.

У теці шаблону виконайте:

```sh
latexmk main.tex
```

І все — та сама команда працює однаково на Windows (у командному
рядку MiKTeX Console або звичайному `cmd`/PowerShell) і на Linux.
`latexmk` сам розбереться, скільки разів перезапустити XeLaTeX і
`biber`, щоб зміст, посилання й бібліографія були коректні. PDF
з'явиться поряд із `main.tex`.

Щоб прибрати допоміжні файли компіляції (`.aux`, `.log` тощо), не
чіпаючи сам PDF:

```sh
latexmk -c
```

## Що редагувати

- **`config.tex`** — усі ваші особисті дані (факультет, кафедра,
керівник, тема тощо). Це єдиний файл, який редагує майже кожен студент.
- **`main.tex`** — ступінь (`[master]` чи `[bachelor]` в `\documentclass`)
і перелік файлів розділів/додатків, якщо додаєте чи прибираєте якийсь.
- **`chapters/*.tex`**, **`appendices/*.tex`** — власне текст роботи.
- **`bibliography.bib`** — ваші джерела (формат описано прямо у файлі-прикладі).

Титульну сторінку й бланк завдання (`titlepages/`) редагувати
напряму зазвичай не потрібно — вони самі підставляють дані з
`config.tex`.

## Компіляція та типові проблеми

- **"Undefined control sequence" / клас не завантажується** — переконайтесь, що компілюєте 
саме XeLaTeX'ом, а не pdfLaTeX (клас навмисно відмовляється компілюватись під 
pdfLaTeX і скаже про це прямим текстом). `latexmk main.tex` вибирає XeLaTeX сам, 
завдяки `.latexmkrc` — цю команду й використовуйте, а не "Compile" з дефолтним двигуном 
вашого редактора, якщо не налаштували його на XeLaTeX.
- **Перелік посилань порожній** — `biblatex` друкує лише ті джерела, на які є `\cite{...}` десь 
у тексті. Джерело, яке ви не процитували, у списку не з'явиться (це навмисна поведінка, а не помилка).
- **Шрифт виглядає "не як Times New Roman"** — якщо на вашому комп'ютері не встановлено Microsoft Office, шаблон автоматично використовує вбудований Liberation Serif (сумісний за шириною літер замінник). Для фінальної версії роботи на здачу рекомендовано все ж мати встановлений справжній Times New Roman (він є в комплекті Office) — подробиці в `docs/ARCHITECTURE.md`.

## Структура репозиторію

```
kpithesis.cls           клас: усе форматування за ДСТУ 3008:2015
config.tex              ваші дані (єдине, що редагує більшість студентів)
main.tex                збирає документ докупи
titlepages/             титульна сторінка й бланк завдання (2 ступені)
chapters/               текст роботи по розділах
appendices/             додатки
bibliography.bib        джерела
fonts/                  резервний шрифт (Liberation Serif + ліцензія)
docs/ARCHITECTURE.md    чому шаблон побудований саме так
```

## Ліцензія

Шаблон поширюється за ліцензією CC0 (див. `LICENSE`) — робіть із ним
що завгодно. Шрифт Liberation Serif у теці `fonts/` має власну
ліцензію OFL (`fonts/OFL.txt`), яка дозволяє вільне поширення разом із
цим шаблоном.
